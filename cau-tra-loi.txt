Để xuất và đồng bộ dữ liệu Quiz giữa **WordPress (LearnPress)** và **Next.js** theo 2 chiều, giải pháp tối ưu nhất là sử dụng **LearnPress REST API** kết hợp với **Webhooks** hoặc **Server-Side Trigger / API Routes**.

---

### Kiến trúc tổng quan đồng bộ 2 chiều

* **Chiều 1: WordPress $\rightarrow$ Next.js (Khi Admin cập nhật Quiz/Câu hỏi)**
Sử dụng Webhook hoặc Hook PHP trong WordPress để gửi tín hiệu/data sang Next.js qua Revalidation API (ISR) hoặc Endpoint trung gian.
* **Chiều 2: Next.js $\rightarrow$ WordPress (Khi Học viên nộp bài / Retake Quiz)**
Next.js gọi trực tiếp các REST API Endpoints của LearnPress để ghi nhận kết quả hoặc tạo lượt làm bài mới.

---

### Chiều 1: WordPress $\rightarrow$ Next.js (Đồng bộ cấu trúc Quiz)

#### Bước 1: Gọi LearnPress REST API từ Next.js

LearnPress cung cấp sẵn REST API endpoint để lấy thông tin Quiz:

* **GET Quiz detail:** `GET [https://your-site.com/wp-json/lp/v1/courses/](https://your-site.com/wp-json/lp/v1/courses/){course_id}` hoặc query qua Custom REST API endpoint.

Trong Next.js (App Router), bạn lấy dữ liệu Quiz bằng `fetch` và cấu hình Revalidation:

```typescript
// app/quiz/[id]/page.tsx
async function getQuizData(quizId: string) {
  const res = await fetch(`https://your-site.com/wp-json/wp/v2/lp_quiz/${quizId}`, {
    headers: {
      'Authorization': `Bearer ${process.env.WP_JWT_TOKEN}` // nếu cần authen
    },
    next: { tags: [`quiz-${quizId}`] } // Dùng On-Demand Revalidation
  });

  if (!res.ok) throw new Error('Failed to fetch quiz');
  return res.json();
}

```

#### Bước 2: Bắn Webhook từ WordPress khi Admin bấm "Save Quiz"

Thêm đoạn code sau vào file `functions.php` của Theme WordPress để tự động báo cho Next.js xóa cache và cập nhật bài thi mới:

```php
add_action( 'save_post_lp_quiz', 'sync_quiz_to_nextjs', 10, 3 );
function sync_quiz_to_nextjs( $post_id, $post, $update ) {
    if ( wp_is_post_revision( $post_id ) ) return;

    $nextjs_webhook_url = 'https://your-nextjs-app.com/api/revalidate';
    
    wp_remote_post( $nextjs_webhook_url, array(
        'method'      => 'POST',
        'headers'     => array('Content-Type' => 'application/json'),
        'body'        => json_encode(array(
            'secret'  => 'YOUR_MYSTERY_SECRET_KEY',
            'quiz_id' => $post_id,
            'tag'     => "quiz-{$post_id}"
        )),
    ));
}

```

#### Bước 3: Handler Revalidate trong Next.js Route Handler

Tạo file `app/api/revalidate/route.ts`:

```typescript
import { revalidateTag } from 'next/cache';
import { NextRequest, NextResponse } from 'next/server';

export async function POST(request: NextRequest) {
  const body = await request.json();
  
  if (body.secret !== process.env.MY_REVALIDATE_SECRET) {
    return NextResponse.json({ message: 'Invalid token' }, { status: 401 });
  }

  if (body.tag) {
    revalidateTag(body.tag); // Xóa cache của Quiz tương ứng ngay lập tức
    return NextResponse.json({ revalidated: true, now: Date.now() });
  }

  return NextResponse.json({ revalidated: false });
}

```

### Chiều 2: Next.js $\rightarrow$ WordPress (Đồng bộ làm bài & nộp bài)

Khi học viên làm bài trên Next.js, dữ liệu (câu trả lời, lượt retake, thời gian) cần được push ngược về WordPress để ghi vào các bảng `wp_learnpress_user_items` và `wp_learnpress_user_itemmeta`.

#### Bước 1: Tạo Custom REST API Endpoint trong WordPress

Do endpoint gốc của LearnPress dùng session/nonce rất phức tạp, bạn nên viết 1 endpoint tùy chỉnh trong `functions.php` để nhận kết quả thi từ Next.js:

```php
add_action( 'rest_api_init', function () {
    register_rest_route( 'custom-lp/v1', '/submit-quiz', array(
        'methods'  => 'POST',
        'callback' => 'handle_nextjs_quiz_submission',
        'permission_callback' => '__return_true', // Nên bổ sung kiểm tra JWT token ở đây
    ));
});

function handle_nextjs_quiz_submission( $request ) {
    $params     = $request->get_json_params();
    $user_id    = $params['user_id'];
    $quiz_id    = $params['quiz_id'];
    $course_id  = $params['course_id'];
    $answers    = $params['answers']; // Mảng [ question_id => answer_value ]

    // 1. Tạo hoặc Cập nhật bản ghi trong LearnPress
    $user_item_id = learn_press_user_start_quiz( $quiz_id, $user_id, $course_id );
    
    // 2. Chấm điểm & Lưu câu trả lời vào database
    if ( $user_item_id ) {
        $user_quiz = learn_press_get_user_item( $user_item_id );
        // Lưu thông tin chi tiết câu trả lời vào wp_learnpress_user_itemmeta
        learn_press_update_user_item_meta( $user_item_id, 'question_answers', $answers );
        
        // Hoàn thành bài thi
        $user_quiz->complete();
        
        return new WP_REST_Response( array( 'status' => 'success', 'item_id' => $user_item_id ), 200 );
    }

    return new WP_REST_Response( array( 'status' => 'error' ), 400 );
}

```

#### Bước 2: Gửi dữ liệu nộp bài / Retake từ Next.js

Tại giao diện Next.js, khi người dùng bấm **Submit** hoặc **Retake**:

```typescript
// components/QuizForm.tsx
async function handleSubmitQuiz(userAnswers: Record<number, any>) {
  const res = await fetch('/api/quiz/submit', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      userId: 12, // ID user hiện tại
      quizId: 456,
      courseId: 101,
      answers: userAnswers,
    }),
  });

  const data = await res.json();
  if (data.status === 'success') {
    alert('Nộp bài thành công!');
  }
}

```

### Quy trình tổng kết

```
[ WordPress Admin ] --(1. Sửa Quiz)--> [ Webhook ] --------> [ Next.js Revalidate Tag ]
                                                                      |
[ Frontend Next.js ] <--(2. Get Quiz Data via REST API)---------------
         |
  (3. Học viên nộp bài)
         |
         v
[ Route Handler Next.js ] --(4. POST Submit API)--> [ WP Custom REST Route ] --> [ Write to DB ]

```

* **Xác thực (Authentication):** Khuyên dùng plugin **JWT Authentication for WP REST API** để đảm bảo request gửi từ Next.js đến WordPress có đính kèm `Bearer Token` chính chủ của user đang đăng nhập.
